# Maintainers

Maintainers review and merge changes, cut releases, and answer for the
project's security and conduct routes. [GOVERNANCE.md](GOVERNANCE.md) describes
how maintainers are added, step back, and decide.

The repository is owned by the `Sinetti-ai` GitHub account and commits so far
carry sinetti.ai author addresses. Individual maintainers are listed here by
name and GitHub handle as they take up the role.

## Emeritus maintainers

None yet.

## Duties

- Review pull requests against [CONTRIBUTING.md](CONTRIBUTING.md); require the
  tests and evidence a change claims.
- Keep CI, dependency updates, and the security route working.
- Handle vulnerability reports under [SECURITY.md](SECURITY.md).
- Cut and sign releases under [RELEASE.md](RELEASE.md).
- Record decisions in issues, discussions, or pull requests.
