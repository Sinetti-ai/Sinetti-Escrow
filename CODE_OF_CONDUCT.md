# Code of conduct

This project follows the
[LF Decentralized Trust Code of Conduct](https://lf-decentralized-trust.github.io/governance/governing-documents/code-of-conduct/).
It applies to every participant in every project space: issues, pull requests,
discussions, and any meeting or channel run on the project's behalf.

Report conduct concerns to the maintainers at team@sinetti.ai. Reports are
handled in confidence by maintainers who are not the subject of the report.
Security vulnerabilities are a separate route; see [SECURITY.md](SECURITY.md).
